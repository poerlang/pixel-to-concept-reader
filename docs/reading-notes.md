# 读书笔记：AIKR、知觉与 Buffer

> 来源：`C:\pdftest4\build`、`C:\pdftest4\nal_build` 的相关章节，以及 `C:\pdftest4\articles` 中王培的文章。
> 只保留与当前“通用经验 + Buffer + NAL”有关的原则；旧形状/词项路线不再作为目标。

## 1. 智能 = 知识和资源不足时的适应能力

- AIKR 不是“知识越多越好”，而是有限时间/空间下如何选择、压缩、修订。
- 所以不能靠堆专用特征；瓶颈通常是**选择/分组/预算**，不是词项数量。

## 2. 概念的意义来自经验

- 词项不是外部对象的符号；它的意义由它在经验中的关系决定。
- 因此 `round`/`convex` 可以是概念名，但不能是感知层的 `isRound()`/`convexHull()`。
- 概念由反复观察、比较、复合、修订形成；没有经验就没有概念。

## 3. 知觉是主动的，不是模板匹配

- 知觉不是把像素匹配到模板；是选择看什么、如何分组、如何预期。
- 通道只提供普通测量；真正的知觉是 Buffer 的选择、比较、复合、修订。
- 把“注意”写进扫描顺序，等于把注意放错层；注意应在 Buffer/预算里。

## 4. Buffer 是唯一的时空结构

- 书A ch13：固定感受野、局部缓冲、划分；每周期只处理少数高优先级项。
- 书A ch5：袋是概率优先级队列；Buffer 是一次性处理，适合事件。
- Buffer 只提供共现、顺序、成员；`near`/`aligned`/`continues`/`between` 如果出现，
  只能是学习到的概念，不是 Buffer 的函数。

## 5. 交集复合是压缩，不是枚举

- 书A ch7：`∩` 用更紧凑的方式概括经验。
- 不枚举所有两两关系；只让高优先级观察在预算内复合。
- 复合词项越复杂，越需要复用/预测/压缩来支付租金。

## 6. 通用性的判据

1. 删掉了哪个专用项？
2. 新能力由哪条 Buffer/NAL 机制产生？
3. 参数是资源（容量/预算/租金/衰减）还是语义权重？
4. 命名是否通用？
5. 是否只是“不崩”？

**通用性不来自更多专用特征，而来自在证据不足时仍能选择、分组、修订和节省。**
